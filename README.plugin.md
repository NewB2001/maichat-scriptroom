# 麦麦剧本聊天室 —— 壳阶段插件

**本目录是「壳阶段」的交付物。** 所有数据都是假数据（Mock），插件不碰任何真实数据。

## 这一阶段做了什么

| 板块 | 对应需求 | 状态 |
| --- | --- | --- |
| 房间管理（列表 / 新建（置顶） / 改名 / **导出（入口）** / **删除（✕）** / 切换） | FR-01 | ✅ 假数据 |
| **房间成员管理**（**下游**：成员从上游挑，房间级配置：添加 / 移除 / 替换） | FR-01 / FR-13 | ✅ 假数据 |

| **私聊：独立入口**（左栏不显示房间；右栏是**「消息发送」**窗口：选角色 + 大文本框；**换角色下拉 → 聊天记录跟着换**） | FR-02 | ✅ 假数据 |

**段（segment）**：一段 = 我方一次提交的多条台词 + 紧随其后的一轮 Bot 回复（一轮可含多个 Bot、每人多条行）。
月光宝盒的截断就是在这串段上做的：点某段的「回到此处」→ 确认气泡 → 该段及其后灰显标「已作废」
（保留、不消失、不重排），输入区上方出现状态条「舞台已回到第 N 段之前，从这里继续」。
作废后可以继续提交，新段延续段号往下编、插在舞台位置、正常渲染。

**剧情旁白**是固定身份（`webui` / `g1_narrator`），**不可被扮演** ——
它不在候选池里，角色下拉里永远不会出现。剧情段与普通段同权，同样能被「回到此处」截断。

每个角色身份都绑定固定的「平台 + 账号」（设计文档第 4 章「平台身份固定」），只模拟这一层。
**platform 一律是 `webui`** —— 自定义平台名会被宿主的「适配器名单」拦掉，聊天运行实例根本建不起来；
`webui` / `internal` 在心流白名单里无条件放行。假数据即真格式，下一阶段接真通道时不用再改。

接话对象的候选**只列当前房间里的 Bot**；一个都不勾就是随机，顺序也只在这个房间的 Bot 里排。

剧本框不是自由文本框：每行是「角色下拉 + 台词」，下拉里**只有「我的角色」**（Bot 是接话方，不是说话方），
插件收到的是结构化的 `lines[{speaker_member_id, speaker, text}]`，**不需要从文本里猜谁说的**。

**剧本行的顺序是有意义的**：它决定 Bot 读到台词的先后（等同真实群聊里群友发言的先后）。
↑↓ 调完的顺序会原样进 `lines` 数组、再原样进时间线 —— 下一阶段接真通道时不用改管道。

**「我的角色」是全局的、有顺序的**（不挂房间）：增删改排序都只动这一份；
删一个角色会同时从所有房间的成员名单里移除它。
群聊剧本框的角色下拉按这个顺序排，且只列在当前房间里的那些。

群聊和私聊是**两套完全独立的窗口**：群聊是「一行一句」的剧本框，私聊是「选角色 + 大文本框」的消息发送。
私聊没有接话勾选 —— 私聊只有一个对方。

三个面板（房间 / 群员 / 剧本）各自能滚到底，内容不会被裁掉。

## 这一阶段**没有**做什么（下一阶段的事）

maim 网关递话 / 收话、真实调度、SQLite 存档、剧本重演、接入校验的真实探测逻辑。

## 边界（铁律自查）

- **不改宿主源码**：本插件只有新增文件，没有改动 `MaiBot 安装目录` 下任何既有 `.py`。
- **不装消息处理类插件**：本插件 `capabilities` 为空，不注册 Tool / Command / Hook / EventHandler / Gateway。
- **不使用自定义平台名**：涉及 platform 的地方一律是 `webui`（自定义平台会被适配器名单拦掉）。
- **不碰 Bot 数据**：不读写真实数据库，不写 `bot_config.toml`；房间与时间线只存在于 Runner 进程内存里，
  插件重载即回到初始假数据。
- **头像也不落盘**：换头像走**纯页面内存** —— 页面把图缩到 128×128、变成 data URI 传给插件，
  存在插件内存里，**一个字节都不写磁盘**。
  本插件**不申请** `webui.claim_upload` 能力（`capabilities` 是空的），
  因此宿主的上传通道对本插件**完全关闭**（端点返回 403「页面未声明该上传操作」）。
  填肉阶段头像随聊天室自己的 SQLite 存档走（data URI 存 TEXT），仍不碰宿主上传通道。
  （`data/plugins/maichat.scriptroom/uploads/` 里那个 67 字节 PNG 是早期上传测试留下的残留，
  本插件不再使用该目录。）
- **单文件插件**：`plugin.py` 没有兄弟模块，避开「宿主按路径加载、sys.path 不含插件目录」的裸 import 陷阱。

## 装 / 刷新 / 卸

**装**：把整个目录复制到 `MaiBot 安装目录\plugins\maichat_scriptroom\`（麦麦一号的 plugins 目录）。

宿主有一个插件文件监视器（`src/plugin_runtime/integration.py` → `_handle_plugin_source_changes`）：
只要 `plugins/` 下有 `_manifest.json` 或 `*.py` 变化，就会重载插件运行时并重新发现插件。
所以**复制进去通常十几秒内自动生效，不需要重启麦麦**。

> 装载失败的典型报错：`插件 xxx 必须实现 on_config_update()`。
> 宿主要求 SDK 插件**显式覆盖** `on_load()` / `on_unload()` / `on_config_update()` 三个方法，
> 继承基类的空实现不算数（`src/plugin_runtime/runner/plugin_loader.py:669-674`）。

**刷新页面**：
- 只改了 `webui/index.html` → 点 WebUI 里的「重载页面」按钮即可（只重读 HTML）。
- 改了 `webui.json` 或 `plugin.py` → 需要重载插件：在 WebUI 聊天里发 `/pm plugin reload maichat.scriptroom`，或重启麦麦。

**看**：WebUI 侧栏 → 插件 → 剧本聊天室；或直接访问
`http://127.0.0.1:8001/extensions/maichat.scriptroom/studio`。

**卸**：删掉 `MaiBot 安装目录\plugins\maichat_scriptroom\` 整个目录，然后 `/pm plugin reload maichat.scriptroom`（或重启麦麦）。

## 演示说明

- **真实节奏**：@点名 ≈ 23s、无点名自发接话 ≈ 50s（实测参考值 23s / 51s）。一轮 3 个 Bot 可能要 2 分钟以上。
- 等待一律走**真实节奏**（@点名 ≈23s、无点名自发接话 ≈50s），界面里没有加速开关。
- 随机轮次里有约 12% 的概率某个 Bot 保持沉默（拟真沉默）；沉默**不会**在时间线上留下任何发言，
  只在底部调试面板的「沉默（不进时间线）」里列出 —— 这是 FR-09 的规矩，故意做出来给你看。

## 两个页面层的坑（别再踩）

1. **别用 `var(--maibot-viewport-height)` 当页面高度。**
   那个变量是父页面异步发来的「可见区高度」，窗口缩放后有滞后，会让页面卡在旧高度、底下留空白。
   用 `height: 100%`（html/body/#app 三层都 100%），它直接跟 iframe 实际尺寸走。
   （另外宿主 main 区域底部恒有 85px 空白，在 iframe 外面，插件页填不满也没法填。）
2. **iframe 是 opaque origin + 标签页后台定时器降频到 1Hz。**
   等待逻辑必须按**墙上时钟**算截止时间，不能「数 tick」。

## 一个插件侧的坑（别再踩）

**别改模块级常量里的字典对象。** 群员登记表是**插件实例自己的副本**
（`self._members = {id: dict(m) for m in MEMBER_POOL}`）——
之前直接改 `MEMBER_POOL` 里的 dict，改个名字就让「按名字查人」的预置时间线查不到人，
`KeyError` 把整个 `bootstrap` 打成 502。凡是要被用户改的数据，一律先拷副本。
